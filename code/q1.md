# Question 1
## Which country in Africa has the largest number of spoken languages?

```{code-cell} python
import pandas as pd

africa = pd.read_csv('https://raw.githubusercontent.com/rfordatascience/tidytuesday/main/data/2026/2026-01-13/africa.csv')

africa
```

```{code-cell} python
language_counts = (
    africa
    .groupby('country')['language']
    .nunique()
    .reset_index(name='num_languages')
    .sort_values('num_languages', ascending=False)
)

language_counts
```

Cameroon has the most spoken languaes with 95.
